## 학습 흐름이 끊기지 않도록

오늘의 학습 현황에서 시작해 필요한 개념을 찾아 읽고, 원하는 방식으로 퀴즈를 만든 뒤, 남은 오답과 북마크를 기록에서 다시 확인합니다.

## 앱을 이루는 네 가지 화면

- **오늘** — 학습 현황과 분야별 진도를 확인하고 바로 학습을 시작합니다.
- **학습** — 개념, 수식, 가정, 체크리스트와 출처를 요소별로 읽습니다.
- **퀴즈** — 분야, 학습 모드, 난이도와 문제 수를 직접 선택합니다.
- **기록** — 정답률, 오답, 북마크와 개인 학습 데이터를 관리합니다.

## 내 기기 안에서 작동합니다

학습 콘텐츠와 기록은 Android 기기에서 사용할 수 있도록 설계했습니다. 로그인, 광고, 분석, 결제 없이 개인 학습에 집중하며 인터넷 연결이 없어도 핵심 기능을 계속 사용할 수 있습니다.
